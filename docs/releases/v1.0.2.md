本次更新增强签到计划和 macOS 应用内更新，并改进 Trae 模型目录连接失败的处理。

- 签到支持按分钟、小时、天间隔，以及每天、指定星期（可多选）、指定日期执行一次；默认每天 07:00，遵循偏好设置中的时区。
- 应用与系统定时任务共用计划、运行锁和执行记录，避免并发重复执行；保留旧的自定义分钟间隔和平台开关。
- 执行方式使用原生选择框，改善下拉交互；旧系统任务可在界面更新为新计划。
- macOS 在线更新改为一次确认后自动下载、校验、安装并重启；准备更新失败时保持当前网关可用，支持安装失败后重试。
- Trae 目录查询分别记录超时、连接失败、HTTP 拒绝和格式错误，保留失败地址及尝试次数。
- 只读目录 GET 遇到暂时性连接故障、超时、响应中断或 HTTP 502/503/504 时最多重试一次，不重放对话、不更换账号，保留原有轮询调度。
