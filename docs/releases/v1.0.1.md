本次更新修复 Trae 图片输入和客户端工具桥接，并保留跨端轮询调度。

- 支持 Trae 图片上传和资源引用，保留历史消息及工具结果中的图片；上传失败会明确报错。
- 修复 Remote `finish` 名称和参数分段到达时，被误判为内置工具执行的问题。
- 为客户端工具分配请求内别名，强化工具调用输出约束，减少与 Trae 内置工具混淆。
- 新增 `toolBridgeVersion`、`blockedRemoteTool` 和停止会话确认信息，便于诊断真实的上游工具调用。
- 校验图片格式、尺寸和大小，限制图片下载访问本机或私网地址。
- 停用从独立 WorkBuddy、Qoder、Trae 应用自动迁移数据的逻辑；账号可通过备份或手动导入。
- 更新接入设置中的重试说明，与现有 Qoder 输出前拒绝、排队重试行为保持一致。

验证范围：本地离线测试和原生 macOS 安装包校验；发布流程还会完成三平台构建与离线测试。未使用真实账号进行 Trae 上游复测，Remote Agent 仍可能尝试内置工具，此类调用会继续被拦截并记录。
