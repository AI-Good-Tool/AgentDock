本次更新为 Trae 云端反代增加会话自动清理。

- Trae 固定使用 Remote 云端会话；正常完成、请求失败或取消后自动清理本次创建的会话，不提供本地会话模式开关。
- 请求取消时继续等待已发出的创建请求取得会话 ID，随后停止未完成任务并删除，减少云端列表残留。
- 清理待办独立加密保存，启动后及每 5 分钟补清理；跨进程文件锁保护活动会话，并避免签到任务覆盖待办。
- 清理只处理本网关记录归属的会话，不读取云端列表或删除旧会话；清理失败不会替换模型回答或原请求错误。
- 请求详情展示本次云端会话清理结果，接入页面更新 Trae 能力说明。

清理为尽力执行：上游不可达、账号失效、创建响应丢失或保存归属前进程退出，仍可能留下云端会话。取消、失败重试、实例并发及加密持久化均通过本地模拟接口验证；未使用真实账号重放请求或删除历史会话。

验证：本地 185 项测试通过、1 项原有测试忽略，前端类型检查与生产构建通过；Apple Silicon 应用及 DMG 已通过签名完整性、版本、架构和隔离启动校验。安装包使用临时签名，未做 Apple 公证。
