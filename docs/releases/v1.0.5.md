# AgentDock 1.0.5

账号池新增卡片勾选、当前筛选全选、批量删除；单个删除与批量删除统一由后端处理。已有批量导出接入卡片选择，可跨 WorkBuddy、Qoder、Trae 及地区导出所选账号。WorkBuddy 新增单个删除菜单。完整保留同步的 WorkBuddy 5.9.3 SDK 和请求头修复。

WorkBuddy 删除保留来源 Switch 账号库；Qoder/Trae 删除对应本地记录，客户端登录保留。跨平台操作返回逐账号结果，失败记录保留；Qoder 持久化失败会如实报错。保留旧单账号删除命令的 `ok` 返回格式。详见 [账号管理说明](../ACCOUNT-MANAGEMENT.md)。

审查未发现未解决的阻断问题。复用既有持久化流程、共享选择函数及 WorkBuddy 导出模块，不增加依赖。WorkBuddy crate 保持 0.1.17，避免无关 helper 签名指纹变化。

验证：工作区 Rust 共 250 项通过、1 项原有 DMG 实机测试忽略；Node 26 项通过；Vue 类型检查和 Vite 生产构建通过。演示数据界面验证覆盖跨平台全选、地区切换清理隐藏选择、导出预选及删除后其他地区账号保留。未调用生产接口或操作真实账号。macOS Apple Silicon 包使用本地 ad-hoc 签名，未公证；完整性与源码指纹见 `releases/*.manifest.json`。
