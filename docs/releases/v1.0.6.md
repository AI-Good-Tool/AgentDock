# AgentDock 1.0.6

包含 WorkBuddy 5.9.3 适配、设备 SDK 超时后的原生调用生命周期修复、`view_image` 辅助用途，以及三种平台账号卡片的单个删除、当前筛选全选、批量删除和批量导出。WorkBuddy 保留来源 Switch 账号库；Qoder/Trae 删除本地账号记录，客户端登录保留。范围见 [账号管理说明](../ACCOUNT-MANAGEMENT.md)。

## 本轮审查修复

- Qoder 的积分查询、领取和刷新原本可用旧账号列表覆盖并发删除结果。所有账号库写入改为文件锁内读取最新数据并局部更新，网络操作在锁外进行；删除、备注、导入、采集及 OAuth 保存共用事务接口。损坏文件拒绝写入，临时文件使用唯一名称和 0600 权限。
- WorkBuddy 拒绝为已删除账号写回迟到的积分、鉴权和模型限额；签到保留历史但不重建当前账号状态。统一网关也拒绝为已删除账号重新创建鉴权暂停标记。请求凭据与观测响应均检查来源 ID、UID 和地区。
- 三种平台账号操作菜单改为自然高度并靠右对齐，移除默认 200px 的裁切。浏览器使用虚构账号确认菜单末项完整可见。

复核未发现未解决的阻断问题。WorkBuddy 导出模块和选择范围函数与 WorkBuddy-Api 相同；官方传输桥保留既有 64 MiB 上限和 `AGENTDOCK_READ_SESSION` 入口，设备 SDK 和请求头逻辑一致。WorkBuddy crate 继续使用 0.1.17，避免无关的 helper 签名指纹变化；未新增依赖。

工作区 Rust 共 255 项通过（根模块 91、core 33、Qoder 17、Trae 34、WorkBuddy 80），1 项原有真实 DMG 安装测试忽略。Node 26 项通过，Vue 类型检查与 Vite 生产构建通过。回归覆盖删除时的迟到响应、Qoder 并发局部更新、损坏账号库保留及来源身份变化拒绝。

使用临时账号库、合成 SDK 和回环服务验证，未主动调用真实 OAuth、续期、签到或生产模型接口。Windows 未实机验证。macOS Apple Silicon 包为本地 ad-hoc 签名，未公证；完整性和源码指纹见 `releases/*.manifest.json`。
