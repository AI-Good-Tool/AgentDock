本次更新统一平台图标，并加强账号登录状态提示与反代失效处理。

- Qoder 使用白色圆角底座、深绿双卡片与切换箭头。
- Trae 使用白色圆角底座、黑绿双向箭头与中央双菱形。
- 侧边栏、工作台、账号池、模型目录、签到与接入设置统一复用平台图标，适配浅色与深色主题。
- README 六张截图更新为新版图标；使用虚构账号数据，手机号、邮箱、UID 与本地路径脱敏，API Key 保持隐藏。
- 登录过期或鉴权失效的账号显示红色卡片警示，历史积分标为缓存；反代检测到明确的鉴权失败后自动停用该账号，并在重启后保持停用，修复登录后需手动开启。
- WorkBuddy 在调度前读取最新登录元数据，避免导入时的旧有效期或后台扫描缓存误停用刚续期的账号；只对已过期且参与当前路由的账号先尝试自动续期，避免健康账号增加调度延迟。
- Trae 保留 HTML 401 和明确业务鉴权错误的分类；模型权限、限流、网络与服务故障不会因此自动停用账号。
- 串行保存账号开关与自动停用原因，避免并发停用多个账号时丢失状态。

- WorkBuddy 官方桌面授权补齐地区端点、版本与可用设备上下文；默认启用 Token 自动续期，按账号串行、失败退避，并在保存前核对凭据版本。
- 导入当前 WorkBuddy 账号支持读取本机官方加密登录态，更新已有凭据并立即刷新过期状态，不回退到旧凭据。
- 手机号展示支持从同 UID 的 Token 读取完整号码；真正只有脱敏号码时明确提示。

- WorkBuddy 卡片新增手动「续期」按钮，自动续期关闭时仍可使用；已失效的刷新凭据明确提示重新登录。
- 复核修正共享账号库写入竞争、旧请求误停用新登录、后台续期退避阻塞 401 恢复、部分字段加密及旧 JSON 地区识别问题；账号记录 ID 不允许改绑到其他用户或地区。
- 续期响应未提供有效期时，清除上一枚访问令牌的旧到期时间，避免续期成功后仍被判定过期。
- Qoder 的 HTTP / SSE 鉴权失败及 Trae 的目录、会话、事件请求失败均关联实际使用的凭据版本；旧请求不再停用已更换凭据的账号，当前凭据确实失效时仍正常停用。
- 手机号作为卡片标题、备注或继承的展示名时，同样遵循隐藏设置；旧账号缺少展示配置时也保持脱敏。
- WorkBuddy 续期增加同机进程间的账号锁，桌面应用与系统签到进程共用；短有效期按剩余寿命安排续期，未知有效期按最近续期时间检查，避免刚成功就重复刷新。
- Qoder / Trae 登录、续期与新凭据导入后清除旧鉴权失败标记，反代仍保持关闭；过期备份和旧请求结果不会误恢复账号。
- Trae 运行事件统一在运行日志中查看，启动时恢复已保存的历史；清空时同步清理历史，并按写入队列顺序清空日志文件，避免旧记录重新出现。

验证：224 项工作区测试（含双进程续期、登录恢复与历史日志回归）、3 项账号库专项测试、4 项手机号展示回归测试及 2 项解密读取测试通过，1 项原有测试忽略、3 项依赖本机传输环境的测试未运行；前端类型检查与生产构建通过。手机号显示 / 隐藏、手动续期后的状态恢复及反代保持停用已通过虚构数据的浏览器预览检查；本轮新增后端逻辑使用临时账号库与本机模拟接口验证。未使用真实账号调用刷新接口或重放反代请求。
