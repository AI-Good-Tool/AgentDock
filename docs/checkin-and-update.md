# 签到计划与应用内更新

签到计划支持每 N 分钟、每 N 小时、每 N 天、每天、指定星期（可多选）和指定日期执行一次。新计划默认为每天 07:00，日历时间遵循偏好设置中的时区。按天间隔代表每 N × 24 小时；需要固定钟点时使用“每天”。启动 10 秒后的签到为独立开关。

旧版本默认的 60 分钟计划升级为每天 07:00，其他自定义分钟间隔和平台开关保留。系统任务与应用使用同一个计划；旧的 10:05 / 22:05 任务需要在界面点击“更新任务”。系统任务每分钟检查是否到期，应用退出后仍可执行，设备需处于运行状态。两者共享运行锁和执行记录，避免同时重复签到。重启后已到期的重复计划合并执行一次，指定日期的计划只预定一次执行。手动执行不受定时开关限制。

macOS 关于页检查到新版本后，点击“在线更新”并确认，即自动下载、校验 SHA256、准备新版应用、安装并重启。无需下载完成后再次点击安装。下载期间可以取消；下载或准备失败会保留当前应用和网关服务。替换后若启动失败，更新助手会尝试回滚；如果新版进程仍在运行但未确认就绪，会保留旧版备份以供恢复。

应用需从可写目录中的 `.app` 运行；从 DMG 或系统应用转移目录运行时，应先将应用移到“应用程序”文件夹。Windows 下载校验完成后会打开安装向导并退出应用，安装完成后按向导提示启动。

Trae 在创建对话前会查询 Remote 模型目录。目录查询的超时、连接/传输失败、HTTP 拒绝和格式错误分别记录，并保留目录地址、HTTP 状态（收到响应时）和尝试次数。只读目录 GET 遇到暂时性连接错误、超时、响应中断或 HTTP 502/503/504 时最多重试一次，每次最多等待 20 秒；鉴权失败、限流和格式错误不自动重试。此操作不会重放对话、改变模型或更换账号。
